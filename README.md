
# Weather App (Flutter)

Учебное приложение на Flutter с двумя экранами и навигацией. Интерфейс выполнен по макету Figma.

## Описание
Приложение отображает экран поиска города и карточку погоды (UI), а также экран деталей с параметрами (UI).
Функционал для UI-элементов может быть не реализован (по требованию задания), главное — соответствие макету.

## Экраны
1) **HomeScreen** — ввод города, кнопка, карточка погоды, блоки интерфейса по макету.
2) **DetailScreen** — детальная информация (температура, описание, параметры: влажность, ветер, давление и т.д.).

## Навигация
Навигация реализована стандартным способом через `Navigator.push()` (переход с HomeScreen на DetailScreen)
и `Navigator.pop()` (возврат назад).
